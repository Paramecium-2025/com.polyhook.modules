## 🚀 快速开始

### 环境要求

- Android 设备已 Root（Magisk / KernelSU）
- 已安装 LSPosed 或 Xposed 框架

### 安装步骤

1. 从 [Releases](https://github.com/Paramecium-2025/com.polyhook.modules/releases/latest) 下载最新版 APK
2. 在 LSPosed 管理器中启用本模块
3. 勾选需要 Hook 的目标应用
4. 重启目标应用即可生效
